# 1C Аналитик — Meeting Bridge

Windows-приложение для аналитика 1С на живом созвоне. Meeting Bridge одновременно захватывает микрофон и звук собеседника через loopback, распознаёт русскую речь локально, ведёт стенограмму и может давать подсказки через OpenAI API.

## Самый простой вариант для коллеги

Коллеге не нужны Git, Python, PowerShell, `pip` или ручное скачивание STT-модели.

После публикации Release достаточно дать ему одну ссылку:

**[Скачать последнюю версию 1С Аналитик](https://github.com/Aleksey341/1C_Analitik/releases/latest/download/1C-Analitik-Setup.exe)**

Дальше пользователь делает только следующее:

1. скачивает `1C-Analitik-Setup.exe`;
2. запускает установщик и нажимает **Установить**;
3. после установки приложение стартует автоматически;
4. при первом запуске один раз вставляет свой OpenAI API key;
5. выбирает микрофон и устройство собеседника `[Loopback]`;
6. нажимает **Старт**.

Установщик сам содержит приложение, Python runtime, зависимости, 9 аналитических skills и русскую STT-модель. На рабочем столе создаётся ярлык **1С Аналитик**.

> Windows всё равно попросит пользователя подтвердить скачивание/запуск EXE. Полностью запускать программу из браузера без подтверждения пользователя нельзя и не нужно обходить эту защиту.

## Что умеет

- захват микрофона пользователя и системного звука собеседника;
- локальное STT на базе sherpa-onnx;
- живой текст встречи в окне;
- ручной и автоматический ответ ИИ;
- режим короткой реплики «Вслух»;
- кнопка **Новый кейс** для отделения нового вопроса от предыдущего контекста;
- профильные skills для 1С: диагностика, БУ/НУ/НДС, закрытие месяца, движения документов, анализ отчётов, сверка данных, требования, тест-кейсы и анализ встречи;
- сохранение диалога и формирование протокола.

## Системные требования для готового установщика

- Windows 10/11 x64;
- интернет для обращений к OpenAI API;
- собственный OpenAI API key;
- наушники/динамики, для которых Windows/PyAudioWPatch предоставляет устройство **[Loopback]**.

Python отдельно устанавливать не требуется.

## Первый запуск

Если OpenAI API key ещё не настроен, программа сама покажет окно **«1С Аналитик — первый запуск»** и попросит вставить ключ. Ключ сохраняется только в локальном `config.yaml` на компьютере пользователя и не публикуется в GitHub.

После открытия основного окна:

1. выберите свой микрофон;
2. в поле **Собеседник (loopback)** выберите устройство с пометкой `[Loopback]`;
3. нажмите **Сохранить настройки**;
4. нажмите **Старт**.

## Основные кнопки

| Кнопка | Назначение |
|---|---|
| Старт / Стоп | начать или остановить захват встречи |
| Устройства | перечитать список аудиоустройств |
| Сохранить настройки | сохранить выбранные микрофон и loopback |
| Автоответ ИИ | автоматически отвечать после реплики собеседника или вернуть SKIP |
| Вслух | короткий ответ, пригодный для произнесения на созвоне |
| Ответ ИИ | принудительно запросить помощь по текущему контексту |
| Новый кейс | начать новый независимый аналитический кейс без очистки стенограммы |
| Сохранить диалог | сохранить копию встречи |
| Сделать протокол | сформировать Markdown-протокол |

## OpenAI API key

Каждый пользователь использует собственный ключ. В публичном репозитории реальных ключей нет.

При первом запуске установочной версии ключ вводится через окно программы. Альтернативно можно использовать переменную окружения `OPENAI_API_KEY`.

Локальный `config.yaml` исключён из Git через `.gitignore`.

## Для разработчика: запуск из исходников

Если нужно развивать проект, а не просто пользоваться программой:

```powershell
git clone https://github.com/Aleksey341/1C_Analitik.git
cd 1C_Analitik
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

После установки исходной версии:

```powershell
.\start.ps1
```

## Конфигурация

Публичный шаблон находится в `config.example.yaml`. Локальная рабочая конфигурация — `config.yaml`.

Ключевые параметры стабильной версии:

```yaml
llm:
  model: gpt-5.6-sol
  max_context_lines: 40
  max_tokens: 3000
```

Актуальные экспертные инструкции хранятся в коде и в каталоге `skills/`.

Следующие файлы и каталоги являются локальными и не публикуются в GitHub:

## Автоматическая сборка установщика

Workflow `.github/workflows/release-windows.yml` на Windows автоматически:

1. устанавливает зависимости;
2. запускает тесты;
3. скачивает русскую STT-модель;
4. собирает `MeetingBridge.exe` через PyInstaller;
5. собирает `1C-Analitik-Setup.exe` через Inno Setup;
6. прикладывает установщик к GitHub Release.

После публикации Release постоянная ссылка `/releases/latest/download/1C-Analitik-Setup.exe` всегда ведёт на последнюю опубликованную версию.
