# Meeting Bridge

Windows-приложение для записи диалога на созвоне: микрофон + звук собеседника
(loopback), текст в окне приложения, сохранение диалога и протокола.

## Быстрый старт

1. Двойной клик: **`MeetingBridge.bat`** или ярлык **Meeting Bridge** на рабочем столе.
2. Выберите устройства → **Старт**.
3. Диалог появляется в окне.
4. **Сохранить диалог** или **Сделать протокол** → файлы в папке `transcripts/`.

Для собеседника выбирайте устройство с **[Loopback]** (наушники/динамики).

## Кнопки

| Кнопка | Действие |
|--------|----------|
| Старт / Стоп | Запись речи |
| Автоответ ИИ | Сам отвечает на реплики собеседника (`ИИ:` или SKIP) |
| Ответ ИИ | Принудительный ответ / подсказка по запросу |
| Сохранить диалог | Копия встречи в `transcripts/` |
| Сделать протокол | Markdown-протокол: реквизиты, диалог, решения, поручения |
| Папка сохранений | Открыть `transcripts/` |

## Ответ нейросети

В `config.yaml` блок `llm:`:

- `api_key` — ключ API, или переменная окружения из `api_key_env` (по умолчанию `OPENAI_API_KEY`)
- `base_url` / `model` — OpenAI-compatible endpoint (OpenAI, OpenRouter, Groq, локальный Ollama и т.п.)

Нажмите **Ответ ИИ** — реплика появится в диалоге как `ИИ: …`.

Включите **Автоответ ИИ** — после паузы за собеседником модель сама решит: ответить или `SKIP`.
Параметр `llm.auto_reply_pause_sec` в `config.yaml` (по умолчанию 2.5).
