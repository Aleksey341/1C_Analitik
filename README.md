# 1C Analitik — Meeting Bridge

Windows-приложение для аналитика 1С на живом созвоне. Meeting Bridge одновременно захватывает микрофон и звук собеседника через loopback, распознаёт русскую речь локально, ведёт стенограмму и может давать подсказки через OpenAI API.

## Что умеет

- захват микрофона пользователя и системного звука собеседника;
- локальное STT на базе sherpa-onnx;
- живой текст встречи в окне;
- ручной и автоматический ответ ИИ;
- режим короткой реплики «Вслух»;
- кнопка **Новый кейс** для отделения нового вопроса от предыдущего контекста;
- профильные skills для 1С: диагностика, БУ/НУ/НДС, закрытие месяца, движения документов, анализ отчётов, сверка данных, требования, тест-кейсы и анализ встречи;
- сохранение диалога и формирование протокола.

## Системные требования

- Windows 10/11 x64;
- Python 3.11 или новее;
- интернет для первоначальной установки зависимостей, загрузки STT-модели и обращений к OpenAI API;
- собственный OpenAI API key;
- наушники/динамики, для которых Windows/PyAudioWPatch предоставляет устройство **[Loopback]**.

## Быстрый старт для нового компьютера

### Вариант 1 — через Git

```powershell
git clone https://github.com/Aleksey341/1C_Analitik.git
cd 1C_Analitik
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

### Вариант 2 — без Git

1. На GitHub нажмите **Code → Download ZIP**.
2. Распакуйте архив в обычную папку, например `C:\AI\1C_Analitik`.
3. Откройте PowerShell в этой папке.
4. Выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

`install.ps1` автоматически:

1. создаёт локальное окружение `.venv`;
2. устанавливает зависимости из `requirements.txt`;
3. создаёт локальный `config.yaml` из `config.example.yaml`, если его ещё нет;
4. скачивает русскую STT-модель в `models/`.

## OpenAI API key

После установки откройте локальный файл `config.yaml` и заполните:

```yaml
llm:
  api_key: "sk-..."
```

Вместо записи ключа в файл можно использовать переменную окружения `OPENAI_API_KEY`.

**Важно:** `config.yaml` исключён из Git через `.gitignore` и не должен публиковаться в репозитории. Каждый пользователь использует собственный API key.

## Запуск

После установки дважды щёлкните:

```text
MeetingBridge.bat
```

Либо из PowerShell:

```powershell
.\start.ps1
```

При первом запуске:

1. выберите свой микрофон;
2. в поле **Собеседник (loopback)** выберите устройство с пометкой `[Loopback]`;
3. нажмите **Сохранить настройки**;
4. нажмите **Старт**.

Если STT-модель отсутствует, её можно скачать прямо из приложения кнопкой **Модель STT**.

## Основные кнопки

| Кнопка | Назначение |
|---|---|
| Старт / Стоп | начать или остановить захват встречи |
| Устройства | перечитать список аудиоустройств |
| Сохранить настройки | сохранить выбранные микрофон и loopback |
| Автоответ ИИ | автоматически отвечать после реплики собеседника или вернуть SKIP |
| Вслух | короткий ответ, пригодный для произнесения на созвоне |
| Ответ ИИ | принудительно запросить помощь по текущему контексту |
| Новый кейс | начать новый независимый аналитический кейс без очистки стенограммы |
| Сохранить диалог | сохранить копию встречи |
| Сделать протокол | сформировать Markdown-протокол |

## Конфигурация

Публичный шаблон находится в `config.example.yaml`. Локальная рабочая конфигурация — `config.yaml`.

Ключевые параметры стабильной версии:

```yaml
llm:
  model: gpt-5.6-sol
  max_context_lines: 40
  max_tokens: 3000
```

Актуальные экспертные инструкции хранятся в коде и в каталоге `skills/`.

## Skills

В стабильную версию входят 9 skills:

- `evidence-driven-diagnosis`
- `accounting-bu-nu-vat`
- `1c-requirements-analysis`
- `1c-test-case`
- `meeting-analyst`
- `1c-data-consistency`
- `1c-closing-month`
- `1c-document-movements`
- `1c-report-analysis`

За один запрос выбирается не более трёх наиболее релевантных skills.

## Файлы пользователя

Следующие файлы и каталоги являются локальными и не публикуются в GitHub:

- `config.yaml` — настройки и API key;
- `live-transcript.md` — текущая стенограмма;
- `transcripts/` — сохранённые встречи;
- `*.log` — диагностические логи;
- `models/` — скачанная STT-модель;
- `.venv/` — локальное Python-окружение.
