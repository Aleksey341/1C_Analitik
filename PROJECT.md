# PROJECT.md

## 1. Что такое 1C Аналитик
`1C_Analitik` - Windows-приложение Meeting Bridge для аналитика 1С на живом созвоне. Оно захватывает микрофон и loopback, локально распознаёт русскую речь, ведёт стенограмму, подключает профильные skills и формирует AI-подсказки и протокол встречи.

## 2. Продуктовые принципы
- Живой помощник аналитика должен сохранять контекст встречи и не смешивать независимые кейсы.
- Профессиональные ответы опираются на профильные skills и доступный evidence.
- Локальная STT-обработка используется для речи, сетевой вызов применяется к AI-подсказкам.
- Пользовательские ключи и стенограммы остаются локальными и не попадают в Git.
- Установщик должен позволять пользователю работать без ручной установки Python и STT-модели.

## 4. Основной поток
`microphone + loopback -> local STT -> transcript/context -> skill selection -> OpenAI -> UI / protocol`

Контур поставки:
`source -> tests -> PyInstaller -> Inno Setup -> GitHub Release`

## 5. Безопасность и данные
Локальными считаются:
- `config.yaml`;
- API key пользователя;
- `live-transcript.md`;
- `transcripts/`;
- `*.log`;
- локальные модели и окружение.

Эти данные не должны попадать в Git или release assets. Любое изменение схемы передачи стенограммы во внешние сервисы требует отдельного продуктового решения и обновления документации.

## 6. Критерии качества
Изменение считается подтвержденным, когда применимый набор проверок проходит:
- unit/regression tests;
- manual/auto packet tests;
- long-context или end-to-end smoke test, если затронут контекст;
- build/release workflow, если затронут installer;
- типовой и граничный профессиональный кейс, если изменена логика skills.
