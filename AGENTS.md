# Meeting Bridge — заметки для агента Cursor (опционально)

Диалог и протоколы ведутся **в приложении Meeting Bridge**, не в чате Cursor.

Если пользователь всё же просит разобрать запись:
1. Смотри файлы в `transcripts/` (`dialog-*.md`, `protocol-*.md`) или `live-transcript.md`
2. Не вызывай MCP `session_start` / `session_stop` пока открыт GUI
