# Auto-reply ИИ в Meeting Bridge

Дата: 2026-09-04

## Цель

ИИ слушает живой диалог и сам отвечает как участник (`ИИ:`), когда это уместно.
Кнопка «Ответ ИИ» остаётся для принудительного ответа.

## Поведение

1. Переключатель GUI «Автоответ ИИ» (по умолчанию выкл; сохраняется в `config.yaml` → `llm.auto_reply`).
2. Пока сессия в `listening` и автоответ включён:
   - после новой финальной реплики `Собеседник:` ждём `llm.auto_reply_pause_sec` (по умолчанию 2.5 с);
   - если за паузу появилась реплика `Я:` — автозапрос отменяется (пользователь отвечает сам);
   - если последняя учтённая реплика собеседника уже отвечена — повторно не зовём;
   - пока идёт запрос — второй не стартуем.
3. Модель либо возвращает короткую реплику участника, либо ровно `SKIP` (в диалог не пишем).
4. Кнопка «Ответ ИИ» всегда форсирует ответ (режим подсказки/ответа по полю вопроса).

## Защита

- Не триггерить на роли `Я` и `ИИ`.
- Не писать в диалог пустые ответы и `SKIP`.
- Ошибки API показываем в статусе, не спамим messagebox при каждом автосбое (только warn_label).
